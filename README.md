# Задание №1: Проект Home Gym(AI-Fitness)

**Бизнес-модель:** B2C (Business-to-Consumer)

## Elevator Pitch
Многим людям не хватает времени на походы в спортзал, а при самостоятельных занятиях дома быстро падает мотивация и возникает риск получить травму из-за неправильной техники. Мы предлагаем мобильное приложение с индивидуальными программами, которое осуществляет трекинг движений через камеру смартфона в реальном времени. Наша главная фишка — AI-тренер прямо в телефоне: он дает подсказки при ошибках и считает только правильные повторения, обеспечивая безопасность без похода к живому специалисту. В результате как обычные люди, так и те, кому критически важна правильная техника для ЛФК, получают качественные тренировки в любом месте. Будет бесплатный доступ к ограниченному числу базовых упражнений и платная подписка с полным функционалом.
